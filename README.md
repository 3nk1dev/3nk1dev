## Featured guide

### [Beyond the Second Brain: Cross-LLM Knowledge & Memory](https://github.com/3nk1dev/beyond-the-second-brain)

A public, work-in-progress guide to keeping reviewed knowledge and useful context portable across AI models using Markdown, source records, and bounded handoffs.

Start with the [guide](https://github.com/3nk1dev/beyond-the-second-brain/blob/main/GUIDE.md) and its teaching templates. The focus is on reviewing what is worth keeping, recording where it came from, and giving another model enough context to continue the work without handing over everything.

This is a documented approach, not an installable app or a service that synchronizes providers' built-in memories. The personal vault stays private; the public repository shares the method and teaching materials.
